# ACP schema (vendored)

Pinned copy of the Agent Client Protocol v1 schema, used as the reference for the hand-written wire
types and by conformance tests. Do not edit by hand.

- Source: https://github.com/agentclientprotocol/agent-client-protocol/tree/schema-v1.24.1/schema/v1
- Tag: `schema-v1.24.1`

To update, download `schema.json` and `meta.json` from a newer `schema-v*` tag, update the tag above
and review the changelog for changes that affect the `ACP` module.
